# AI Video Director — 八步 AI 短视频导演工作流（Agent Skill）

> 把一句话创意变成一份可直接投喂视频生成模型的完整拍摄方案。
> 剧情设计 → 人物锁定 → 场景风格 → 色卡设计 → 分镜设计 → 动作设计 → 表情声音 → 连续性约束

## 这是什么

一个成品级 Agent Skill：当你给 AI 一个视频想法（或一段翻车的提示词），它会按固定八步流程产出一份**拍摄方案（Shooting Bible）**——包含角色参考图分配表、带 HEX 色值的色卡、逐秒分镜表、**可直接复制投喂的逐镜提示词**、声音设计表和生成后 QA 检查表。

核心判断：**视频质量的瓶颈不在模型，而在你能否把创意变成一份清晰、可执行的拍摄方案。** 模型每次只看到一段提示词，一致性是用结构化方案"喂"出来的，不是抽卡抽出来的。

## 解决什么问题

| 症状 | 根因（工作流对应步骤） |
|------|----------------------|
| 中途变脸、两人特征融合 | 02 人物锁定：参考图一图一职 + 逐镜一致性指令 |
| 镜间明显色差 | 04 色卡：语义色板 + 逐镜 HEX |
| 动作假、两人同时动像排练 | 06 动作设计：因果动作链 + 先动方 |
| 表演过载、五官乱动 | 07 表情声音：每镜一个动作 + 一个微表情 |
| 跳帧、越轴、道具漂移 | 08 连续性约束：逐镜负面约束 + QA 检查表 |
| 镜间接不上、PPT 感 | 05 分镜设计：动作链映射 + 景别跳级规则 |

翻车后不必整篇重写：`references/10-troubleshooting.md` 提供**症状 → 失守步骤 → 修复动作**对照表，只改失守的那一步，重新生成那一镜。

## 安装

### 通用方式（任何支持 Agent Skill 的运行时）

把 `ai-video-director/` 目录复制到你的 skills 目录：

```bash
# 项目级
cp -r ai-video-director <你的项目>/.skills/

# 用户级（跨项目可用）
cp -r ai-video-director ~/.skills/
```

### Claude Code

```bash
mkdir -p ~/.claude/skills
cp -r ai-video-director ~/.claude/skills/
```

重启会话后，Skill 会出现在可用技能列表中。

### 手动安装

1. 下载/克隆本仓库
2. 将 `ai-video-director/` 整个文件夹放入你的 skills 目录
3. 确认 `SKILL.md` 位于该文件夹根目录（不要直接放进 skills 根）

## 使用

直接说人话即可触发，例如：

- "我有一个想法：女主向对手发起挑战，最终解除对方武装。帮我做成 30 秒视频。"
- "这段 Seedance 提示词生成出来变脸了，帮我修。"
- "给这组参考图写一套分镜提示词，保持人物一致。"
- "做一条英伦魔法学院风格的对决短视频。"

Skill 会依次执行八步，产出拍摄方案；把 `## 5. 逐镜提示词` 各镜复制进你的视频生成工具即可。

### 万能公式

```
剧情设计 → 人物锁定 → 场景风格 → 色卡设计 → 分镜设计 → 动作设计 → 表情声音 → 连续性约束

@图片：参考人物、服装和场景
@视频：参考动作、运镜和节奏
@音频：参考声音和音乐
```

## 适用模型

工作流与具体模型解耦，已按以下模型的提示词习惯设计（逐镜投喂 + @素材引用）：

- Seedance 2.5 / 即梦
- 可灵（Kling）
- Vidu
- Sora、Veo 等其他支持参考图的视频模型

核心原则通用于任何"单镜提示词 + 参考素材"的生成范式；若目标模型不支持 `@图片N` 引用语法，把引用改写为模型要求的附件/垫图方式即可，字段结构不变。

## 设计原则

1. **AI 负责生成画面，你负责导演** —— 方案的清晰度决定上限。
2. **逐镜自包含** —— 模型生成第 5 镜时看不到第 1 镜的提示词，每镜必须带齐 @ 引用、色卡、约束。
3. **一图一职** —— 一张参考图只锁一个职责，锁多了两头都飘。
4. **一个镜一个动作链环节** —— 每镜只承担动作链一环，节奏来自切换本身。
5. **一个动作一个微表情** —— 表演过载是"假"的头号原因。
6. **改失守的那一步，不整篇重写** —— 症状对照表定位后单镜重生成。
7. **关键要求说清楚 > 篇幅长** —— 不是每条视频都要写几千字。

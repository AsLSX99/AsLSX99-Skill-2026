# 完整示例：《魔法学院对决》30 秒 / 9 镜

> 展示八步工作流走完全程后的产出形态。可作为新项目的填写参照。

## 0. 一句话核心事件

- 核心事件：女主向对手发起挑战，经过短暂交锋，最终成功解除对方武装。
- 目标时长：30 秒｜分镜规模：9 镜
- 动作链：挑战 → 试探 → 格挡 → 反击 → 反转 → 收尾
- 情绪曲线：挑衅 → 谨慎 → 吃力 → 得意 → 震惊 → 释然

| 环节 | 秒区间 | 情绪 |
|------|--------|------|
| 挑战 | 0.0–4.5s | 挑衅 |
| 试探 | 4.5–10.5s | 谨慎 |
| 格挡 | 10.5–15.0s | 吃力 |
| 反击 | 15.0–21.0s | 得意 |
| 反转 | 21.0–27.0s | 震惊 |
| 收尾 | 27.0–30.0s | 释然 |

## 2. 场景与风格

- 场景：英伦哥特魔法学院大厅，古老石墙与高耸拱窗，长桌纵向延伸，双人对峙于大厅中央
- 风格：电影级真人摄影质感，35mm 胶片颗粒，浅景深
- 光线：冷色环境光从高窗落入（左上），与桌面温暖烛光交织，明暗比偏高
- 氛围：神秘压抑 → 对决紧张 → 收尾释然
- 基调句（逐镜粘贴）：
  ```
  英伦哥特魔法学院，电影级真人摄影质感，古老石墙与高耸拱窗，
  冷色环境光 #5D6C7A 与温暖烛光 #C99051 交织，神秘而紧张的氛围。
  ```

## 3. 色卡

| 语义位 | HEX | 用途 | 主辅比 |
|--------|-----|------|--------|
| 冷石蓝灰 | #5D6C7A | 建筑背景、环境阴影 | 70% |
| 深墨绿 | #1F3C35 | 学院服装 | — |
| 银灰色 | #A8B2B8 | 金属与装饰 | — |
| 琥珀金 | #C99051 | 烛光与面部暖光 | 30% |

- 肤色：不入卡，保持真实血色
- 禁区色：高饱和正红 #FF0000、荧光绿 #39FF14
- 主辅关系：冷色约 70%，暖光约 30%，暖光只落于桌面与面部侧缘

# 09 万能公式与提示词组装

> 本步产出：可直接复制投喂模型的逐镜提示词。这是八步工作流的最终接口。

## 万能公式

```
剧情设计 → 人物锁定 → 场景风格 → 色卡设计 → 分镜设计 → 动作设计 → 表情声音 → 连续性约束
```

有参考素材时按类型指定：

```
@图片：参考人物、服装和场景
@视频：参考动作、运镜和节奏
@音频：参考声音和音乐
```

## 单镜提示词组装顺序（固定字段顺序，模型对开头和结尾更敏感）

```
1. 镜号与时间：镜头N ｜ X.X–Y.Ys
2. 景别·运镜·光线：85mm 近景 ｜ 固定微推 ｜ [第3步光线句]
3. @引用：@图片N [各自锁定职责]（该镜在场的全部引用）
4. 场景基调句：[第3步基调句精简版]
5. 内容（动作链）：[第6步动作链原文，含先动方与结束状态]
6. 表情：[第7步顺序式微表情 + 停顿]
7. 台词（如有）：[人物]："[台词]"，[声线+语气]，口型同步
8. 声音：[环境声/动作声/音乐]
9. 色卡：[本镜主色HEX + 用途]
10. 负面约束：[通用约束 + 该镜定制1–3条]
```

### 完整示例（可直接改写复用）

```
镜头3 ｜ 4.5–6.6s
85mm 近景 ｜ 固定机位微推 ｜ 冷色环境光与琥珀烛光交织
@图片1 锁定波特（五官/发型），@图片6 锁定她举起的魔杖（形制/颜色）；
全程保持人物五官、服装和发型一致。
英伦哥特魔法学院，电影级真人摄影质感，古老石墙背景。
内容：马尔福先举起魔杖，波特视线先落在魔杖上，再移回她的脸；
马尔福保持举杖姿势不动。动作沉稳，无位移。
表情：视线移动 → 眉头轻微放松 → 停顿半秒后开口；轻、明知故问的轻微调侃，不夸张。
台词：波特："Still angry about yesterday?"（清亮女声，语气轻，口型同步）
声音：远处壁炉噼啪声，衣料摩擦，低音量弦乐铺底
色卡：冷石蓝灰 #5D6C7A（背景）＋ 琥珀金 #C99051（面部暖光）
负面约束：五官不得变化；魔杖不得换手持；不越轴；口型与台词同步；
不出现高饱和红绿；动作不跳帧不重复。
```

## 全片级提示词（部分模型需要一段总述）

总述只放**跨镜不变**的内容，不要重复每镜细节：

```markdown
《[片名]》总述：
一句话核心事件：[第1步]
角色与参考图：[第2步分配表 + 一致性指令]
场景风格：[第3步基调句]
色卡：[第4步色卡表]
声音基调：[第7步音乐走向一句话]
通用负面约束：[第8步通用约束]
```

## 提示词长度控制

- 单镜提示词 150–400 字为宜；超过 600 字拆字段精简（砍修饰词，保动作链与约束）。
- **关键要求说清楚 > 篇幅长**：不是每条视频都要写几千字。
- 逐镜调整策略：第一次生成后，只修改翻车镜的对应字段，不整篇重写。

## 交付前最终检查

- [ ] 每镜都带该镜在场的 @ 引用与一致性指令
- [ ] 每镜都有色卡行与负面约束
- [ ] 动作链结束状态 = 下一镜开头
- [ ] 台词时长 ≤ 镜长 − 1 秒
- [ ] 时间轴首尾相接、总和 = 片长

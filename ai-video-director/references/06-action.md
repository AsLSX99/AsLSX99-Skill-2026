# 06 动作设计：让人物真正动起来

> 本步产出：每镜的动作链（谁先动 → 发生什么 → 停在哪）。很多 AI 视频看着假，问题不在画质，在动作逻辑。

## 核心判断

不要只写"两个人展开激烈的魔法战斗"——这是名词堆砌，模型只能随机发挥。**动作要写成有序的因果序列**，让每个动作都有原因和结果，画面才有真实感。

## 操作步骤

### 1. 把每镜内容展开为动作链

固定格式：**A 动作 → B 反应 → 结果状态（停在哪）**。

```
举起魔杖 → 发射魔法 → 对方格挡 → 身体后撤 → 重新站稳
```

规则：

- **必须写明谁先动**：双人镜不写先后，模型会生成两人同时做动作，看起来像对口型排练。
- **必须写结果状态**：动作完成后停在哪里（站位、朝向、道具位置），这是下一镜的起点，也是防跳帧的锚。
- **链长 3–5 个动作**：单镜超过 5 个动作必然做不完，模型会加速或跳过中间帧。

### 2. 复杂动作单独交代三件事

打斗、舞蹈、器械操作等复杂动作，逐项写清：

1. **谁先动，谁受影响**：被击方的位移方向、幅度。
2. **动作的空间轨迹**：从哪到哪（"魔杖从腰侧划至肩高"），不写轨迹模型会瞬移。
3. **完成后停在哪**：站位、重心、朝向、道具位置。

### 3. 与分镜表对齐

每镜动作链的**最后一帧 = 下一镜的第一帧**（除非该镜是转场镜）。逐镜检查：

```
镜2 结束：马尔福后撤半步，魔杖斜指地面
镜3 开始：马尔福保持魔杖斜指地面，波特视线落在魔杖上 ✓
```

对不上就回去改分镜表的内容行，不要靠模型"自己接上"。

### 4. 速度与节奏标注

给每镜动作标注节奏词，模型会据此决定帧间变化幅度：

| 节奏词 | 适用 | 示例 |
|--------|------|------|
| 爆发 | 反击、突进 | 格挡后瞬间反击 |
| 迅疾 | 试探、闪避 | 三次快速试探 |
| 沉稳 | 蓄力、对峙 | 缓缓举杖 |
| 缓慢 | 收尾、反转余波 | 武器落地、身体松弛 |

## 动作链模板（写入逐镜提示词的"内容："字段）

```markdown
### 镜[N] 动作设计
- 先动方：[角色]
- 动作链：[动作1] → [动作2] → [动作3]
- 受影响方反应：[谁] [位移方向/幅度] [受击/格挡/躲闪]
- 结束状态：[站位] [朝向] [道具位置]
- 节奏：[爆发/迅疾/沉稳/缓慢]
- 提示词原文："先[动作1]，随后[动作2]，[受影响方]向[方向]后撤[幅度]，最终[结束状态]。"
```

## 与前后步的接口

- 输入：第 5 步每镜的内容行（本步将其展开）。
- 输出：提示词"内容："字段原文 + 第 8 步"动作不跳帧/不重复"检查项。
- 联动：动作触发的表情变化归第 7 步，但**表情必须挂在动作链的具体节点上**（"格挡瞬间眉头收紧"，而不是"全程紧张"）。

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 写名词不写序列 | 动作随机、方向乱 | 改写为 A→B→C 因果链 |
| 不写谁先动 | 双人同时动作，像排练 | 显式标注先动方 |
| 不写结束状态 | 镜间接不上、跳帧 | 每镜补"停在哪"，与下镜开头对齐 |
| 单镜动作超 5 个 | 加速、丢帧、动作变形 | 拆镜或砍到 3–5 个 |
| 无速度标注 | 全片一个节奏 | 按节奏词表逐镜标注 |
| 轨迹缺失 | 瞬移、穿模 | 写空间轨迹（从哪到哪） |

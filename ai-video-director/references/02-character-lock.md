# 02 人物锁定：先把角色固定下来

> 本步产出：角色参考图矩阵 + 一致性指令原文。多人物、多镜头的视频里，这是最重要的一步——人物不稳定，后面的分镜再好也没用。

## 为什么这步最重要

模型每次生成只看到当前提示词。"第 7 秒的女主和第 2 秒的女主是同一个人"这个事实，必须由参考图 + 明确指令携带过去。没有锁定，抽卡就是重新抽一个人。

## 操作步骤

### 1. 为每个角色准备参考图矩阵

每个主要角色（一般 1–3 个）准备三类图，各司其职：

| 图类型 | 锁定什么 | 要求 |
|--------|---------|------|
| 人物近景 | 五官、发型、气质、妆容 | 正脸清晰、光线均匀、无遮挡 |
| 人物三视图 | 服装、体型、比例、配饰 | 正/侧/背同套服装，站姿中性 |
| 表情/姿态参考（可选） | 本片要用的神态 | 覆盖情绪曲线上的 2–4 个关键表情 |

道具（武器、魔杖、信物）单独出图并编号——道具漂移和变脸一样常见。

### 2. 建立参考图分配表

每张图写明"负责锁定什么"，写进拍摄方案：

```markdown
| 编号 | 内容 | 负责锁定 |
|------|------|---------|
| @图片1 | 女主近景 | 五官、发型、气质 |
| @图片2 | 女主三视图 | 服装、体型、比例 |
| @图片3 | 男主近景 | 五官、发型 |
| @图片4 | 男主三视图 | 服装、持械手势 |
| @图片5 | 对决场地 | 场景布局、光源方向 |
| @图片6 | 女主魔杖 | 道具形制、颜色 |
```

分配表的原则：**一图一职**。一张图同时又要锁脸又要锁场景，模型不知道该信哪个，结果两头都飘。

### 3. 写一致性指令原文

固定句式，放进**每一条**分镜提示词的开头（不是只写一次总纲）：

```
@图片1 锁定女主，@图片3 锁定男主，全程保持人物五官、服装和发型一致。
```

多人物时补充角色身份锚点，防止模型把两人的特征融合：

```
女主（@图片1/@图片2）：黑发马尾、深墨绿制服；男主（@图片3/@图片4）：短发、银灰扣饰。两人特征不得互换或融合。
```

### 4. 逐镜检查引用在场

第 5 步写每镜提示词时，**该镜出现的角色必须重新 @ 一遍**。模型生成第 5 镜时看不到第 1 镜的提示词，只在开头声明一次等于没声明。

## 素材使用优先级

```
@视频（动作、运镜、节奏参考）> @图片（人物、服装、场景）> @音频（声音、音乐参考）
```

- @视频 用于锁定"怎么动"，@图片 用于锁定"长什么样"，二者不互相替代。
- 素材在精不在多：单条视频建议 @ 引用 ≤ 8 个，超过后模型对每个引用的注意力被稀释。
- 没有现成参考图时，先用文生图生成近景 + 三视图各 1 张并人工确认，再进入视频流程——**这一步省掉的代价是整条视频重抽**。

## 产出模板

```markdown
## 人物锁定
### 角色档案
- [角色名]：五官特征[...]｜发型[...]｜服装[...]｜体型比例[...]｜标志性道具[...]
### 参考图分配表（如上）
### 一致性指令原文（将逐镜粘贴）
"@图片1 锁定女主，@图片3 锁定男主，全程保持人物五官、服装和发型一致。"
### 逐镜在场检查
镜1：@图片1 @图片2 @图片5 ｜ 镜2：@图片1 @图片4 @图片6 ｜ …
```

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 只在总纲写一次一致性 | 中段开始变脸 | 每镜提示词重新 @ 并附指令原文 |
| 一张图锁多个职责 | 脸对了服装飘 / 场景对了脸飘 | 拆图，一图一职 |
| 参考图光线/风格不一 | 视频里人物色调跳变 | 统一参考图的光线与色彩基调 |
| 角色无身份锚点 | 两人特征融合 | 补充发型/服装等区分性描述 |
| 三视图缺背面 | 转身镜头穿帮 | 补背视图或在负面约束写"转身服装不变" |

# 07 表情与声音：决定视频有没有演技

> 本步产出：逐镜微表情 + 台词 + 声音三层设计。这一步特别容易被忽略，但它决定视频是"有演技"还是"会动的贴图"。

## 核心规则

**每个动作段落只安排一个主要动作、一个微表情变化。** 让人物同时完成太多表演，模型会生成五官乱动的"癫痫脸"——表演过载是 AI 视频"假"的头号原因。

## 一、微表情设计

### 1. 表情 = 顺序，不是状态

写**变化的顺序与时机**，不写形容词状态：

```
女主先移动视线 → 眉头轻微收紧 → 停顿半秒后才缓缓开口
```

而不是：

```
女主表情紧张焦虑（状态词，模型只能全程皱眉）
```

### 2. 表情挂在动作链节点上

从第 6 步动作链取锚点，每个节点最多一个表情变化：

| 动作节点 | 表情变化示例 |
|---------|-------------|
| 看见对手举杖 | 视线先移过去，瞳孔微收 |
| 格挡瞬间 | 眉头收紧，下巴微收 |
| 反击得手 | 嘴角先扬，眼神保持冷静 |
| 武器落地 | 呼吸松下来，肩膀下沉半寸 |

### 3. 时机用"停顿"控制

AI 视频的表演节奏靠**停顿**建立。在提示词里显式写停顿：

- "停顿半秒后开口"
- "视线停留 1 秒，再移回她的脸"
- "动作完成后保持姿势 0.5 秒"

没有停顿标注，模型会把动作和表情连成匀速流水。

### 4. 逐镜字段格式

```markdown
表情：[视线/眉眼动作] → [一个微表情变化] → [停顿] [开口/下一动作]
语气：[轻/重/快/慢] + [情绪词]（如：轻，明知故问的轻微调侃，不夸张）
```

## 二、台词设计

### 1. 台词要素

每条台词写全五项：

1. **内容与语言**：原文（含语种，双语片写清谁说什么语言）。
2. **人物声线**：低沉/清亮/沙哑/少年感。
3. **语气**：轻挑/压抑/颤抖/平静。
4. **时长核对**：台词朗读时长 ≤ 所在镜时长 − 1 秒（留出表情停顿）。英文按 2.5–3 词/秒估算。
5. **口型**：有台词的镜头在负面约束写"口型与台词同步"。

### 2. 台词量控制

- 30 秒视频台词 ≤ 3 句，每句 ≤ 8 秒内容。
- 动作密集的镜（格挡、反击）**不放台词**，动作声已经占满听觉。
- 台词镜优先给近景——远景口型对不准是常见翻车。

### 3. 提示词原文格式

```
台词：波特："Still angry about yesterday?"（85mm 近景，语气轻，淡淡调侃，口型同步）
```

## 三、声音设计

每个动作段落标三层，缺一层就听感单薄：

| 层 | 内容 | 示例 |
|----|------|------|
| 环境声 | 场景底噪，贯穿 | 远处壁炉噼啪、走廊回声 |
| 动作声 | 动作链各节点的拟音 | 杖身碰撞的金属嗡鸣、衣料摩擦 |
| 音乐 | 铺底 + 转折点 | 低音量弦乐铺底，反转处骤停 |

### 声音表模板

```markdown
## 声音设计
| 秒区间 | 环境声 | 动作声 | 音乐 |
|--------|--------|--------|------|
| 0–10.5s | 壁炉噼啪 | 脚步、衣料 | 弦乐低音铺底 |
| 10.5–21s | 同上 | 杖击金属嗡鸣 | 节奏加密 |
| 21–30s | 同上 | 武器落地当啷 | 骤停 → 单音收尾 |
```

音乐转折点对齐第 1 步情绪曲线的转折秒数（本例 21s 反转处骤停）。

## 与前后步的接口

- 输入：第 6 步动作链节点（表情挂点）、第 1 步情绪曲线（语气与音乐走向）。
- 输出：提示词"表情/台词/声音"三个字段 + 第 8 步"口型同步、表演过载"检查项。

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 状态词代替顺序 | 全程一个表情 | 改写"先→再→停顿→然后" |
| 单镜多个表情变化 | 五官乱动 | 每镜一个主要动作+一个微表情 |
| 台词超镜长 | 口型飞、台词被截断 | 按 2.5–3 词/秒核对，砍台词或拆镜 |
| 动作镜塞台词 | 声画打架 | 动作密集镜只留动作声 |
| 无停顿标注 | 表演匀速、假 | 显式写"停顿半秒"等时机 |
| 音乐无转折点 | 情绪曲线断裂 | 转折秒数对齐反转点 |

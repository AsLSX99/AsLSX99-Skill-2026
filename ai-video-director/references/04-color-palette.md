# 04 色卡设计：锁定整部视频的色彩语言

> 本步产出：3–6 个带 HEX 值的语义色板。为什么同一个场景切换镜头后经常出现明显色差？因为你没有给 AI 固定色卡。

## 原则

**统一色彩语言 ≠ 给整部视频叠一层同色滤镜。** 色卡的作用是给每个"语义位置"（建筑、服装、金属、烛光、肤色）指定固定颜色，让不同镜头在同一个位置上取同一个色；人物真实、有血色的肤色永远独立于色卡之外，不参与统一——否则全员尸色。

## 操作步骤

### 1. 扫描场景，列出 4–6 个色彩语义位

从第 3 步的基调卡里提取，常见语义位：

- 建筑/背景主色
- 服装主色（可按角色各一色）
- 金属/道具/装饰色
- 光源色（烛光、火光、霓虹）
- 植物/天空等环境色（户外场景）

### 2. 每个语义位指定 HEX + 用途说明

示例（英伦哥特魔法学院系列）：

| 语义位 | 色值 | 用途 |
|--------|------|------|
| 冷石蓝灰 | `#5D6C7A` | 建筑背景、环境阴影 |
| 深墨绿 | `#1F3C35` | 学院服装 |
| 银灰色 | `#A8B2B8` | 金属与装饰 |
| 琥珀金 | `#C99051` | 烛光与局部暖光 |
| —— | 肤色不入卡 | 保持真实血色 |

### 3. 指定色彩关系（比色值本身更重要）

- **主辅比**：冷色占画面约 70%，暖色约 30%（冷暖对比是这类片子的戏剧来源）。
- **落点**：暖光只出现在哪里（桌面、面部侧缘），避免全画面泛黄。
- **禁区**：明确 1–2 个不该出现的颜色（如"不出现高饱和红/绿"），放进第 8 步负面约束。

### 4. 逐镜携带色卡

每条分镜提示词末尾附**本镜主色**（1–2 个 HEX + 用途），不是每镜都塞全部色卡——每镜只声明该镜画面上真正大面积出现的颜色，否则提示词过载。

```
色卡：冷石蓝灰 #5D6C7A（背景）＋ 琥珀金 #C99051（面部暖光）
```

## 色卡模板

```markdown
## 色卡
| 语义位 | HEX | 用途 | 主辅比 |
|--------|-----|------|--------|
| [背景] | #XXXXXX | [场景] | 70% |
| [服装] | #XXXXXX | [角色] | — |
| [道具] | #XXXXXX | [金属/装饰] | — |
| [光源] | #XXXXXX | [烛光/火光] | 30% |
- 肤色：不入卡，保持真实血色
- 禁区色：#XXXXXX、#XXXXXX（不出现）
- 全片主辅关系：[冷暖/明暗比例一句话]
```

## 与前后步的接口

- 输入：第 3 步的光线色温（HEX 应与光源色一致）。
- 输出：每镜提示词的"色卡："行 + 第 8 步 QA 里的色差检查项。
- QA 对照：生成后逐镜截图比对背景主色，出现明显偏色 → 检查该镜是否漏写色卡行。

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 色卡超 6 色 | 模型不知道信哪个，色差依旧 | 砍到 4–5 色，按语义位合并 |
| 肤色也入卡 | 人物面色发青/发灰 | 肤色独立声明"保持真实血色" |
| 只在总纲写色卡 | 单镜内大面积跑色 | 每镜末尾附本镜主色 HEX |
| 无禁区色 | 胶片颗粒里冒出高饱和杂色 | 负面约束写"不出现高饱和红绿" |
| 各镜主辅比不声明 | 镜间冷暖比例跳变 | 统一"冷70%暖30%"类比例句 |

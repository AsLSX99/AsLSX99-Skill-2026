# 08 连续性与负面约束：减少 AI 翻车

> 本步产出：逐镜负面约束清单 + 生成后 QA 检查表。最后一步是提前告诉模型哪些地方不能出错，并在生成后逐项验收。

## 一、负面约束清单

### 1. 全片通用约束（每镜都带，固定原文）

```markdown
人物不能突然变脸、换装；镜头不能随意越轴；道具不能凭空出现或消失；
动作不能跳帧或重复；场景、光线与色彩不能突然跳变。
```

### 2. 逐镜定制约束（从下表按该镜风险挑选 1–3 条）

| 风险类型 | 触发场景 | 定制约束写法 |
|---------|---------|-------------|
| 变脸/特征融合 | 多人镜、快速转头 | 五官保持 @图片N 一致，两人特征不得互换融合 |
| 换装/服装漂移 | 转身、大幅度动作 | 转身时服装、扣饰、发型保持不变 |
| 越轴 | 双人对峙、环绕运镜 | 保持机位在同一侧，不越轴 |
| 道具漂移 | 魔杖/武器易手 | 魔杖保持 @图片N 形制与颜色，不换手持 |
| 跳帧/重复 | 连击、快速位移 | 动作按顺序完整呈现，不跳帧不循环 |
| 色彩跳变 | 镜间切换 | 背景保持 #5D6C7A，烛光保持 #C99051 |
| 口型失步 | 台词镜 | 口型与台词同步，不张错嘴 |
| 表演过载 | 情绪激动镜 | 表情变化克制，仅一个微表情 |
| 肢体畸变 | 手部特写、持械 | 手指数量正确，握持姿势稳定 |

### 3. 打斗场景特别锁定（三要素）

打斗镜必须额外锁定：

1. **人物站位**：谁左谁右、相对方位（"女主画面左侧，男主右侧"）。
2. **动作方向**：攻击/位移的方向（"由画面右向左"），全片同方向，反打镜才允许反向。
3. **道具位置**：武器在谁手、朝向哪。

不锁这三样，打斗镜最常见的翻车是：两人瞬间换边、武器左右手互换、攻击方向随机。

### 4. 约束放置位置

- 通用约束：粘贴在每条分镜提示词末尾。
- 定制约束：放在该镜提示词内，紧邻对应字段（换装约束紧跟动作描述）。
- 不要把全部约束堆在第一镜——模型生成后面的镜时看不到前面的提示词。

## 二、生成后 QA 检查表

生成后别急着发布，先逐项过这张表。发现问题 → 对照 [10 翻车修复](10-troubleshooting.md) 定位失守步骤 → 只改那一步重新生成该镜。

```markdown
## QA 检查表（逐镜打勾）
### 人物
- [ ] 五官与参考图一致，无中途变脸
- [ ] 服装、发型全程无变化
- [ ] 多人镜无特征融合
### 动作
- [ ] 动作顺序与动作链一致，谁先动没搞反
- [ ] 无跳帧、无循环重复
- [ ] 结束状态与下一镜开头衔接
### 空间
- [ ] 无越轴，站位方向稳定
- [ ] 道具无凭空出现/消失/换手
### 色彩与光线
- [ ] 背景主色与色卡一致，镜间无明显色差
- [ ] 光源方向全片一致
### 声音
- [ ] 口型与台词同步
- [ ] 环境声/动作声/音乐三层齐备，音乐转折在位
### 整体
- [ ] 景别节奏无 PPT 感
- [ ] 时间轴总和等于片长
```

### 验收流程

1. **首帧检查**：每镜抽首帧，比对参考图与色卡——首帧就错的镜直接重生成，别看完 5 秒再发现。
2. **逐镜过 QA 表**：按上表打勾，记录失败项。
3. **连片检查**：把所有镜连起来看一遍，重点看镜间接缝（站位、光线、色彩是否跳变）。
4. **定位修复**：失败项 → 10 文档症状表 → 找到失守步骤 → 只改该步的字段，重新生成该镜。
5. **复查该镜**：重生成后只复查该镜与它相邻的接缝，不整篇重来。

## 产出模板

```markdown
## 连续性约束
- 通用约束原文（逐镜粘贴）：...
- 逐镜定制约束：镜1[...]｜镜2[...]｜...
- 打斗锁定：站位[...]｜方向[...]｜道具[...]
## QA 检查表
（如上，生成后填写结果）
```

至此八步完成 → 进入 [09 提示词组装](09-prompt-assembly.md) 输出最终逐镜提示词。

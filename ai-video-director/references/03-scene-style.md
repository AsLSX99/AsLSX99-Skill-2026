# 03 场景与风格：确定视频的视觉基调

> 本步产出：视觉基调四要素（场景 / 风格 / 光线 / 氛围）。同一个剧情换一种视觉风格，完全就是两部电影——这步决定观众"这是什么片"。

## 四要素定义

| 要素 | 回答的问题 | 示例 |
|------|-----------|------|
| 场景 | 故事发生在哪里 | 英伦哥特魔法学院，古老石墙与高耸拱窗 |
| 风格 | 真人电影、动漫还是 3D CG | 电影级真人摄影质感 |
| 光线 | 自然光、逆光还是戏剧光 | 冷色环境光与温暖烛光交织 |
| 氛围 | 紧张、浪漫、神秘还是轻松 | 神秘中带压抑，收尾转释然 |

四要素必须**一次定死，并在每一镜提示词里重复**——它们是跨镜头色彩、光线不跳变的前提（第 4 步色卡建立在其上）。

## 操作步骤

### 1. 写场景：具体到可建模的物理空间

句式：**地点 + 建筑/地貌细节 + 空间关系**。

- 合格："英伦哥特魔法学院大厅，古老石墙与高耸拱窗，长桌纵向延伸至远处高台。"
- 不合格："一个魔法学校。"（模型只能随机装修）

空间关系决定第 5 步的机位与越轴：先写清光源在哪、出入口在哪、双方站位的相对方位。

### 2. 定风格：三选一，别混

- **真人电影**：写摄影质感词——"电影级真人摄影、35mm 胶片颗粒、浅景深"。
- **动漫**：写画风流派——"日系赛璐璐动画、粗描边、高饱和"或"美漫厚涂"。
- **3D CG**：写渲染质感——"皮克斯风格 3D 渲染、次表面散射、柔光"。

混合风格（"真人+动漫"）只有在明确分区时才可用（如真人场景切入动画回忆），否则模型会在两者之间随机横跳。

### 3. 定光线：给方向和色温，不给形容词

- 方向：顺光 / 侧光 / 逆光 / 顶光 + 具体来源（烛光、窗光、火把）。
- 色温：冷（青蓝）/ 中性 / 暖（琥珀），最好给 HEX，与第 4 步色卡共用数值。
- 强度：明暗比——"高对比戏剧光" vs "低对比柔光"。

示例："冷色环境光从高窗落入，与桌面温暖烛光交织，明暗比偏高，面部保留琥珀侧光。"

### 4. 定氛围：一个词 + 一个落点

氛围词（紧张/浪漫/神秘/轻松/悲壮）写进描述会影响模型的动作幅度与配乐选择。同时写明**氛围在片中的变化**（如：紧张 → 反转 → 释然），与第 1 步情绪曲线对齐。

## 基调卡模板（写入拍摄方案，逐镜粘贴核心句）

```markdown
## 场景与风格
- 场景：[地点 + 细节 + 空间关系]
- 风格：[真人/动漫/3D CG + 质感词]
- 光线：[方向 + 来源 + 色温HEX + 明暗比]
- 氛围：[词] → [词]（对齐情绪曲线）
- 基调句（逐镜粘贴）："英伦哥特魔法学院，电影级真人摄影质感，古老石墙与高耸拱窗，冷色环境光 #5D6C7A 与温暖烛光 #C99051 交织，神秘而压抑的氛围。"
```

## 连续性要点

- **光源方向全片一致**：镜 1 光从左来，镜 5 不能从右来（除非剧情明确转场），否则观众感到"莫名跳了一下"。
- **风格词逐镜重复**，与人物 @ 引用并列放在每条提示词固定位置。
- **场景切换要显式声明**：换场景时在该镜提示词里重新描述场景四要素，不能默认模型还记得上一场。

## 常见错误

| 错误 | 症状 | 修复 |
|------|------|------|
| 场景描述过虚 | 每镜布景都不一样 | 具体到建筑细节 + 空间关系，逐镜重复 |
| 光线只写"氛围感光线" | 镜间光源方向跳变 | 写死方向+来源+HEX，全片统一 |
| 风格混写 | 真人镜头里出现动画质感 | 三选一；混用需显式分区 |
| 氛围无变化曲线 | 全片一个调子，反转无力 | 标注氛围转变点与秒数 |
